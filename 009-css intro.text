Specificity
Specificity is the mechanism browsers use to decide
which css rule should be applied when multiple
rules target the same element.

Example :
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Specificity Example</title>
<style>
p{
color: blue;
}
p{
color: red;
}
</style>
</head>
<body>
<p>Hello World</p>
</body>
</html>

Output:
Red
Reason” both selectors have equal specificity
The last rule wins


Specificity priority chart
Selector type points
Inline style 1000
Id selector 100
Class selector 10
Attribute selector 10
Element selector 1
Universal selector(*) 0

Box Model

The css box model is the concept that every HTML elements
is treated as a rectangle box by the browser,
The box consists of different layers that control:
>content size
>internal spacing
>border
>external spacing
Why do we need Box Model?
>the distance between one element and other elements.
>the border around it.

Box model structure:
Every element has 4 parts:
<!-- Structure of the CSS Box Model -->
+--------------------------------------+
| MARGIN |
| +--------------------------------+ |
| | BORDER | |
| | +--------------------------+ | |
| | | PADDING | | |
| | | +--------------------+ | | |
| | | | CONTENT | | | |
| | | +--------------------+ | | |
| | +--------------------------+ | |
| +--------------------------------+ |
+--------------------------------------+
1) Content
The content area is the actual data inside the element
Example :
Text inside a <p>
Button label
Heading text
2)padding
Padding is the space inside the element , between content
and the border.
Why use padding:
>to avoid the text touching the border.
3)Border
Border is the line surrounding the padding and content
Why use border ?
>to highlight elements
>Create input boxes
>create cards.
4) Margin
Margin is the space outside the box.
>spacing between cards
>spacing between buttons
>spacing between fields.

DEFAULT box-sizing:
box-sizing: content-box;
This means:
‘Width and height apply only on the content
Padding and border are added outside that width/ height.
Issue:
.box{
Width : 300px;
Padding: 20px;
Border: 5px solid black;
}
Will the total width be 300px?
NO
Actual width:
300 + 20 + 20 + 5 + 5 = 350px
Because e width applies only to content when using
content-box.
Solution:
Box-sizing, border-box
When we use :
Box-sizing: border-box;
The given width includes:
> content
>padding
>border
This makes layout easier and more predictable.

Example :
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Box Model</title>
<style>
*{
box-sizing:border-box;
}
body{

padding: 30px;
}
.card{

}
.card h2{
margin-bottom: 10px;
}

margin-bottom: 15px;

}
.card button{
padding:10px 20px;
border: none;

}
</style>
</head>
<body>

Display property

The display property defines how an
element behaves in the layout and how
It occupies spaces.
>it tells the browser:
> should the element start on a new line.
>should is stay in the same line
> Can height/width be applied?
Most important display values:
Block - starts on new line, takes full available width by
default, width and height can be applied, margin and padding
work properly.
Example :
Div
P
H1 to h6
Section
Article
Inline: stays in the same line, only takes as much width as its
content.

Example :
Span
A
Strong
Inline-block:inline-block combines features of both inline and
block
None.: completely removes the element from the browser.

Example :

<html lang="en">

display:inline-block;
width: 150px;
height: 80px;

margin: 10px;
padding: 10px;
}
</style>
</head>
<body>
<h2>Block Elements</h2>

Starts on new line
Each- box appears one below another

Elements appears in the same line

Position Property

In web design , HTML elements appear somewhere on the
page.
By default, elements follow the normal flow - one after
another from top to bottom.
Position
The position property in CSS is used to control how
elements are positioned in a webpage.
It tells the browser:
> should the elements stay in normal flow.
>should it move from its normal place.
>should it stick while scrolling.
Syntax:
Selector{
Position: static | relative | absolute | fixed | sticky;
}
Values of position:
Static - default position
Relative : moves relative to its original position
Absolute - positioned relative to nearest positioned
ancestor
Fixed - positioned relative to the browser viewport
Sticky - behaves like relative + fixed depending on the
scroll.
Example :
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Static</title>
<style>
.box{
width: 200px;
padding: 20px;
margin : 10px;
background-color: aqua;
border: 2px solid black;
position : static;
top: 50px; /* will not visisbly reposition the element */
left: 50px; /* will not visisbly reposition the element */
}
</style>
</head>
<body>
<div class="box">I Am a static box</div>
</body>
</html>
Explanation:
The box remains in the normal flow
Even though top : 50px, left: 50px are written , they do
not reposition the static element

Typography

Typography in css means styling and controlling
the appearance of the text on a web page.
It includes:
>text size
>font family
>text color
>font weight
>line spacing
>letter spacing
>text alignment
>text decoration
>shadow effects on text.
Why typography?
>improves readability
>makes heading and content look professional
>helps users scan content quickly.
Typography

1) Color - the color property is used to change the
color of the text.
Syntax :
Color: red;
Color: #333;
Example :
H1{
Color: blue;
}
This makes the heading text blue.

2) Font-size
The font-size property is used to control the size of
text.
Syntax:
Font-size: 16px;
Font-size: 120%;
Font-size: 2rem;
Example :
P{
Font-size: 18px;
}
This makes the paragraph text 18 pixels.

3) Font-family

What are Shadows?

A shadow in css is a visual effect used to create depth,
separation, and realism by placing blurred or offset shadow
behind an element or text.
Types Of shadows IN CSS
There are mainly two types :
Box-shadow
Used to apply a shadow to anHTML element/ Box
Examples:
Cards
Buttons
Containers
Profile boxes
Product cards
2)Text Shadow - used to apply a shadow to text content
Example :
Headings
Hero titles
Banners
Box-shadow property:
The box - shadow property is used to add one or more
shadows around an element box.
It can create :
> soft card shadows
>floatings effects
>glow effects
Syntax:
Box-shadow: horizontal-offset vertical-offset
blur-radius spread-radius color;
Example :
Box-shadow : 0px 4px 10px 0px rbga(0,0,0,0.2)
Horizontal-offset:
Moves shadow left or right
Positive value - shadows moves to right
Negative value - shadows moves to left
Vertical-offset:
Moves shadow up or down
Positive - shadows moves down
Negative - shadows moves up
Blur-radius :
Controls how soft or sharp the shadow is:
0px - sharp shadow
Higher value - softer shadow
Spread-radius :
Controls how much the shadow expands or shrinks.
Positive: shadow becomes larger
Negative : shadow becomes smaller
Color:
Defines the color of the shadow.
Common used :
Black
Gray
rgba() for transparency.

CSS outline vs Border
Border:
A border is a line drawn around an
element. It is part of the css box model
and occupies space, affecting the
element's total size.
Outline:
An outline is a line drawn outside the
border . it is not part of the box model,
So it does not take up space or change
the elements.
Syntax:
Selector{
Border: 2px solid black;
}
Outline:
Selector{
Outline: 3px solid red;
}
Example:
Border

inside CSS

Color: blue;
Border: blue;
Background : blue;

–primary-color: blue;

What are pseudo-classes
A pseudo-class is a special keyword added to a css property that
styles an element based on its state, user interaction, or position
Unlike normal selectors, pseudo- classes do not require doing
extra classes or ids in HTML
SYntax:
Selector : pseudo-clas{
Property: value;
}
Example :
Button: hover{
Background-color: blue;
}

Animation : colorChange 4s infinite
colorChange - animation name
4s - one complete animation takes 4 seconds
Infinite - the animation repeats forever
0% - at the start of the animation (0 seconds) , the
box is red
25% - at 25% of 4seconds (1second), the box
becomes green
50% - at 50% of 4 seconds(2 seconds) , the box
becomes blue
75% - 75% of 4 second(3seconds) the box becomes
orange
100% - at the end of 4seconds, the box becomes
red again.
Because the animation is infinite , it immediately
starts the next cycle

Animation: bounce 1s infinite alternate;
Bounce - animation name
1s - one bounce takes 1 sec
Infinite - repeated forever
Alternate - plays forward , then backwards, instead
of jumping back to start.

Animation properties
Property purpose
Animation-name keyframes name
Animation-duration animation time
Animation-delay delay
Animation-iteration
-count number of repeats
(1,2,infinite)
Animation-direction normal, reverse,
alternate, alternate-reverse
Animation-fill-mode keeps styles before/after
animation (forwards, backwards, both)
Animation-play-state running or paused
Animation-timing-func speed curve(ease,
liner, etc)
